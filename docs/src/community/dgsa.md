# DGSA — the global ban lists

DGSA (DCS Global Server Admins) is an association of server administrators running the largest DCS
servers. The group exists so that ban-worthy players — cheaters, disruptors — are handled once and
everywhere, instead of server by server.

The result is two ban lists, one for DCS and one for Discord. **DCSServerBot integrates with both**:
a player on one of the lists is refused on your servers.

## Turning it on

The integration lives in the **Cloud** plugin. Its page describes what the plugin checks, which
lists are involved and what it needs from your installation:
[Cloud plugin](../plugins/cloud.md).

## Joining DGSA

Membership is for server administrators who want to take part in the shared lists. Reach out through
the [support Discord](https://discord.gg/h2zGDH9szZ) — the same place as normal support.

!!! note
    You do not have to be a DGSA member to run DCSServerBot, and the plugin is optional. Running
    without it means you keep your own bans and see nobody else's.
