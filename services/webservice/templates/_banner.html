{#- The attention banner — the FIRST element of the console page. It states what needs the reader, IN WORDS, from fields the read models already carry (`console.banner`, built by `pages/dashboard.attention`): a node not heartbeating, a server down or paused, ERROR lines in the visible log, and — last, so it never displaces a fault — the nodes with a DCS update waiting. Every item carries its own dot AND its own sentence, so the state is never colour-only; when the list is empty the banner renders the calm line instead of an empty box (silence is the healthy state). The box's class is `console.banner.tone`: `calm` (nothing listed), `alert` (at least one fault) or `advisory` (only advisory items, e.g. a waiting update). The calm branch stays keyed on `ok`, which means the same thing it always did — nothing at all is listed. Each sentence is translated at RENDER time: the calm line is a `i18n._`-marked literal rendered through the environment's `_`, and an alert is a `_translated` record whose `msgid` + `params` become the sentence in the reader's language (its `text` is the English rendering, kept for the tests and never drawn). It is part of the STATE panel (not a swap target of its own), so a live refresh updates it with the rest of the state. No write control, no link: it reports, it does not act. -#}
