{#- The Settings page — the console's first schema-driven config page. It renders whatever :mod:`services.webservice.configgen` produced from a pykwalify schema: the `render_field` macro (now in `_config_fields.html`, shared with a node's own settings page) turns each `Field` into the control its kind names (see the module docstring of `configgen` for the whole mapping). The right panel shows the file re-serialised as YAML — a DUMP of the parse, not the raw bytes — READ-ONLY by default. `Expert Mode` (the toggle in the panel head, off by default) turns that same panel into an EDITOR (`static/settings-yaml.js`, CodeMirror): every change is checked through the bot's own schema validation, and a save posts the edited document through the SAME atomic write path the form uses.
